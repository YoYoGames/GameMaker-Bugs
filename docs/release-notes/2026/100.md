## 2026.100.0 Release 5 (IDE 1139 / GMS2 RT 1090) - [Changes](https://github.com/YoYoGames/GameMaker-Bugs/issues?q=is%3Aissue%20is%3Aclosed%20milestone%3A2026.1.0%20closed%3A2026-08-13..2026-08-26%20sort%3Aupdated-desc) (27/08/2026)

### Features Added Or Changed

- **Extension Editor Now Allows Code-Injection During macOS Builds [#15809](https://github.com/YoYoGames/GameMaker-Bugs/issues/15809)**
    - One use-case you might require this functionality for is to automatically enable Hardened Runtime support in your builds (and you can see the comments on the issue for the code you need for doing this)
    - However, of course, this will allow you to inject whatever other code your project requires

- **Package Manager Now Shows The Output Log When Errors Occur While On The Start Page [#14913](https://github.com/YoYoGames/GameMaker-Bugs/issues/14913)**
    - This helps increase the visibility of the helper information logged when an error occurs before you have opened a project, which will hopefully allow you to more quickly and easily resolve any issues you can fix yourself
    - Always read **all** of the log output when an error occurs, as the crucial bit of information you need may not be the final line in the log!

- **Prefab Builder Now Available [#14754](https://github.com/YoYoGames/GameMaker-Bugs/issues/14754)**
    - If you have been wanting to try making your own Prefabs for use with GameMaker, then you can now do this - and if you have previously created Local Packages or published to the Marketplace in past GM releases, then it should feel pretty familiar
    - Be aware that this is an early look and there are some known UI issues reported already, so please do search for existing reports before filing new ones

- **Prefab Library Now Able To Remove Prefab Collection Links When That Collection No Longer Exists [#15747](https://github.com/YoYoGames/GameMaker-Bugs/issues/15747)**
    - If, for whatever reason, a prefab collection that your project relies on is removed entirely (it's unpublished), then until now there was no way to remove the link to that missing collection and your project would be stuck unable to open
    - Now, GM will offer you the ability to remove the dead link(s) and restore your project so you can open it again (minus the prefab's content, obviously)

## 2026.100.0 Release 1 (IDE 1083 / GMS2 RT 1046) - [Changes](https://github.com/YoYoGames/GameMaker-Bugs/issues?q=is%3Aissue%20is%3Aclosed%20milestone%3A2026.1.0%20closed%3A<2026-07-02%20sort%3Aupdated-desc) (02/07/2026)

### Features Added Or Changed

- **Building Projects: Compile Errors Window Now Better Shows When An Error Came From A Prefab [#14835](https://github.com/YoYoGames/GameMaker-Bugs/issues/14835)**
    - Previously, prefabs and projects were treated the same way by the compile errors panel and so it was unclear whether a coding mistake came from the main project or a prefab you're using.
    - Now, you'll get a clear distinction and so a prefab error will look something like `Prefab dbg.test.error-1.0.0: Script: myScript1 at line 8 : Assignment operator expected` or `Prefab dbg.test.error-1.0.0: Object: myObject1 Collision Event With Object2 at line 1 : Assignment operator expected`

- **Prefab Library: Double-Clicking Any Asset Now "Previews" It [#14833](https://github.com/YoYoGames/GameMaker-Bugs/issues/14833)**
    - Double-clicking an asset now has the same result as right-clicking that asset and then selecting "Preview" from the content menu, and so double-clicking an asset will now open its viewer

- **Project Load: Show a choice dialog when a required prefab version can't be found, asking how to proceed so you can open the project [#15247](https://github.com/YoYoGames/GameMaker-Bugs/issues/15247)**
    - If your project uses a version of a prefab which is no longer available, then in previous IDEs you would need to manually raise the version of the prefab in the .yyp file outside GameMaker before you would be able to open that project
    - Now, this situation is detected and you are given the choice of removing the prefab link or to change the version that Package Manager will get for you to point at the newest version of that prefab
    - Once you have made your choice, GameMaker will then be able to open the project just fine again

- **UI/UX: Copy Call Stack Panel Contents To The OS Clipboard [#15244](https://github.com/YoYoGames/GameMaker-Bugs/issues/15244)**
    - There is now a new button which will copy the contents of the Call Stack panel to your OS clipboard as text that you can then paste somewhere outside GameMaker
